Approach

設計理念

01

品牌先行

每件作品都有獨立的品牌設定——色彩、字體與語氣以 CSS 變數集中管理，風格一致且易於替換。

02

輕量可維護

不依賴框架與建置工具，原始碼保持可讀；Bootstrap 處理格線，自訂樣式只補足品牌所需。

03

可直接落地

全站響應式，模板一鍵打包下載，並內建 API 指引工具列，標示每頁預期串接的後端端點。
